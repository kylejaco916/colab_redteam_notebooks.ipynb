# colab_redteam_notebooks.ipynb
Run it once — it writes all the .ipynb files and (if you're in Colab) auto-downloads them as a zip. How to run it  In Colab (fastest):      New notebook → paste the whole script into one cell → run.     It writes 7 .ipynb files and downloads colab_redteam_notebooks.zip.     Unzip locally, then in Colab: File →Upload notebook →pick the one you want.
